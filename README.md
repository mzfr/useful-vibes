# useful-vibes

Programs I use or find somewhat useful, all fully vibe-coded using different models at different times.

| Project | What it does |
| --- | --- |
| [diagram-service](diagram-service/) | Hosts Excalidraw and draw.io editors with diagram storage, an HTTP API, and PNG export. |
| [intake](intake/) | Self-hosted tracker for movies, TV shows, and books, with Trakt imports and viewing/reading history. |
| [jsniper](jsniper/) | Finds JavaScript files on websites and scans them for potential secrets using regex patterns. |
| [pi-discord](pi-discord/) | Lets you control a live pi session from Discord. |
| [tasklog](tasklog/) | Manages Markdown tasks through a CLI, terminal UI, and MCP server. |
| [tmux-copy-block](tmux-copy-block/) | Picks and copies visible Markdown code blocks from a tmux pane, with optional cleanup. |
